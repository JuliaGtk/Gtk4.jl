# Julia interface to Pango

Wraps [libpango](https://docs.gtk.org/Pango/) and [libpangocairo](https://docs.gtk.org/PangoCairo/) using GObject introspection, along with the GObject types of [libcairo-gobject](https://www.cairographics.org/) (in the `Pango.Cairo` submodule). Built on [GObjects.jl](../GObjects) and used by [Gtk4.jl](https://github.com/JuliaGtk/Gtk4.jl). Documentation can be found [here](https://juliagtk.github.io/Gtk4.jl/dev/).
